# 🧸 PY32F002Aマイコン搭載 電子オルゴールプロジェクト

安価なPUYA半導体製マイコン「PY32F002A」を使用した、おもちゃ修理・マイコン換装用の電子オルゴールプロジェクトです。開発環境の階層構造を維持した状態で、豊富な楽曲データ（約400ファイル）とソースコード一式を格納しています。

本リポジトリでは、音声再生機能を排し、**電子オルゴールの単一モデル（BTL駆動仕様）**にフォーカスして再構成しています。

---

## 🛠️ 対象プロジェクト（2モデル）

回路構成や使用するパッケージ（ピン数）に合わせて、以下の2つのプロジェクトを選択・ビルドできます。いずれも表現力豊かな電子オルゴール音をスピーカーから大音量で鳴らせる**BTL（Bridge-Tied Load）駆動**に対応しています。

### 1. `orgel_SW_F002A_8_BTL`
* **概要**: 省スペースな **8ピンパッケージ** のPY32F002Aを使用した電子オルゴールです。
* **特徴**: 限られたピン数を有効活用し、スイッチ入力による曲切り替えとBTLスピーカー駆動を両立させます。小型のおもちゃへの組み込みに最適です。

### 2. `orgel_SW_F002A_16_BTL`
* **概要**: ピン数に余裕のある **16ピン（または20ピン）パッケージ** を使用した電子オルゴールです。
* **特徴**: 豊富なI/Oピンを活用し、複数のスイッチ、センサー（CdS、CVDタッチセンサーなど）による制御、LEDの点滅演出（ブリンカー機能）などを盛り込みやすい拡張性の高いモデルです。

---

## 🎵 本プロジェクトの特徴
* **豊富な内蔵曲**: 伝統的な童謡からアニメソングまで、おもちゃに最適な楽曲データ（`.asm`）を多数同梱。
* **エンベロープ/エフェクト制御**: ビブラート、トレモロ、減衰音（エレガンテ/指数関数）など、単なるブザー音ではない「オルゴールらしい表現」を施す仕組み（`enve_*.asm`, `effect_*.asm`）を搭載。
* **BTL駆動による音量確保**: 外部アンプICを極力減らし、マイコンのPWM出力を巧みに利用して直接スピーカーを大音量で鳴らします。
